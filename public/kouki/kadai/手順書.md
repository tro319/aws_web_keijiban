## Dockerインストール

まずDockerをインストール

```bash
sudo yum install -y docker
```

インストールしたら、起動

```bash
sudo systemctl start docker
sudo systemctl enable docker
```


デフォルトのユーザーでも、毎回sudoつけずに起動できるように設定

```bash
sudo usermod -a -G docker ec2-user
```

## Docker Composeインストール

次にDocker Composeをインスト－ル

```bash
sudo mkdir -p /usr/local/lib/docker/cli-plugins/
sudo curl -SL https://github.com/docker/compose/releases/download/v2.36.0/docker-compose-linux-x86_64 -o /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose
```

インストール確認のため、Docker Composeのバージョンを確認

```bash
docker compose version
```


確認できたら、作業用のディレクトリを作成&そこに移動

```bash
mkdir dockerwork
cd dockerwork
```
次に設定ファイルを作成

```bash
vim compose.yml
```

中身の記述は下記

```bash
services:
  web:
    image: nginx:latest
    ports:
      - 80:80
```

記述が終わったら、起動

```bash
docker compose up
```

起動ができたら、`http://パブリックIPアドレス` と入力

`Welcome to nginx!` とブラウザに表示されたら成功

停止させたい時は、さっき起動させたウィンドウに戻り Ctrl+C


## nginxの設定

まずnginx設定ファイル用のディレクトリ作成

```bash
mkdir nginx
mkdir nginx/conf.d
```

設定ファイルを作成

```bash
vim nginx/conf.d/default.conf
```

中身の記述は下記

```bash
server {
  listen        0.0.0.0:80;
  server_name   _;
  charset       utf-8;

  client_max_body_size 6M;

  root /var/www/public;
}
```

`client_max_body_size` は、アップロードされるリクエストの最大サイズを制限する設定

JavaScriptが無効化されており、ブラウザでの画像縮小などが効かない場合もあるので、念のため設定


## compose.ymlの詳細設定

`compose.yml` を下記のように変更

```bash
services:
  web:
    image: nginx:latest
    ports:
      - 80:80
    volumes:
      - ./nginx/conf.d/:/etc/nginx/conf.d/
      - ./public/:/var/www/public/
      - image:/var/www/upload/
    depends_on:
      - php
  php:
    container_name: php
    build:
      context: .
      target: php
    volumes:
      - ./public/:/var/www/public/
      - image:/var/www/upload/
  mysql:
    container_name: mysql
    image: mysql:8.4
    environment:
      MYSQL_DATABASE: example_db
      MYSQL_ALLOW_EMPTY_PASSWORD: 1
      TZ: Asia/Tokyo
    volumes:
      - mysql:/var/lib/mysql
    command: >
      mysqld
      --character-set-server=utf8mb4
      --collation-server=utf8mb4_unicode_ci
      --max_allowed_packet=4MB
  redis:
    container_name: redis
    image: redis:latest
    ports:
      - 6379:6379
volumes:
  mysql: {}
  image:
    driver: local
    driver_opts:
      type: none
      o: bind
      device: ./public/upload/image
```
