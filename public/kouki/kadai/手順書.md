## Dockerインストール

まずDockerをインストール

```bash
sudo yum install -y docker
```

インストールしたら、起動

```bash
sudo systemctl start docker
sudo systemctl enable docker
```


デフォルトのユーザーでも、毎回sudoつけずに起動できるように設定

```bash
sudo usermod -a -G docker ec2-user
```

## Docker Composeインストール

次にDocker Composeをインスト－ル

```bash
sudo mkdir -p /usr/local/lib/docker/cli-plugins/
sudo curl -SL https://github.com/docker/compose/releases/download/v2.36.0/docker-compose-linux-x86_64 -o /usr/local/lib/docker/cli-plugins/docker-compose
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose
```

インストール確認のため、Docker Composeのバージョンを確認

```bash
docker compose version
```


確認できたら、作業用のディレクトリを作成&そこに移動

```bash
mkdir dockerwork
cd dockerwork
```
次に設定ファイルを作成

```bash
vim compose.yml
```

中身の記述は下記

```bash
services:
  web:
    image: nginx:latest
    ports:
      - 80:80
```

記述が終わったら、起動

```bash
docker compose up
```

起動ができたら、`http://パブリックIPアドレス` と入力

`Welcome to nginx!` とブラウザに表示されたら成功

停止させたい時は、さっき起動させたウィンドウに戻り Ctrl+C


## compose.ymlの詳細設定

`compose.yml` を開く

```bash
vim compose.yml
```

下記のように変更

```bash
services:
  web:
    image: nginx:latest
    ports:
      - 80:80
    volumes:
      - ./nginx/conf.d/:/etc/nginx/conf.d/
      - ./public/:/var/www/public/
      - image:/var/www/upload/
    depends_on:
      - php
  php:
    container_name: php
    build:
      context: .
      target: php
    volumes:
      - ./public/:/var/www/public/
      - image:/var/www/upload/
  mysql:
    container_name: mysql
    image: mysql:8.4
    environment:
      MYSQL_DATABASE: example_db
      MYSQL_ALLOW_EMPTY_PASSWORD: 1
      TZ: Asia/Tokyo
    volumes:
      - mysql:/var/lib/mysql
    command: >
      mysqld
      --character-set-server=utf8mb4
      --collation-server=utf8mb4_unicode_ci
      --max_allowed_packet=4MB
  redis:
    container_name: redis
    image: redis:latest
    ports:
      - 6379:6379
volumes:
  mysql: {}
  image:
    driver: local
    driver_opts:
      type: none
      o: bind
      device: ./public/upload/image
```

`web:～` の部分では、ユーザーからのリクエストを受け取り、PHPに処理を渡す設定 & 投稿された画像を表示できるように設定

`php:～` の部分では、ユーザー登録やログイン、投稿、フォロー、各投稿一覧表示など、DBへのアクセスも伴う主要処理が実装できるように設定

`mysql:～` の部分では、ユーザー情報や投稿情報、フォロー情報などの関係を保存/管理できるように設定

`redis:～` の部分では、ログイン状態の維持などに使用する、高度なセッション管理ができるように設定


## nginxの設定

まずnginx設定ファイル用のディレクトリ作成

```bash
mkdir nginx
mkdir nginx/conf.d
```

`default.conf` というファイルを作成

```bash
vim nginx/conf.d/default.conf
```

中身の記述は下記

```bash
server {
  listen        0.0.0.0:80;
  server_name   _;
  charset       utf-8;

  client_max_body_size 5M;

  root /var/www/public;

  location ~ \.php$ {
    fastcgi_pass php:9000;
    fastcgi_index index.php;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    include       fastcgi_params;
  }

  location /upload/image/ {
    alias /var/www/public/upload/image/;
  }
}
```

`client_max_body_size` は、アップロードされるリクエストの最大サイズを制限する設定

JavaScriptが無効化されており、ブラウザでの画像縮小などが効かない場合もあるので、念のため設定



## Dockerfileの設定


`Dockerfile` というファイルを作成

```bash
vim Dockerfile
```

中身の記述は下記

``` bash
FROM php:8.4-fpm-alpine AS php

RUN apk add --no-cache autoconf build-base \
    && yes '' | pecl install redis \
    && docker-php-ext-enable redis

RUN docker-php-ext-install pdo_mysql

RUN install -o www-data -g www-data -d /var/www/upload/image/

RUN apk add autoconf g++ make

RUN pecl install apcu && docker-php-ext-enable apcu

# ディレクトリの権限を変更
RUN chown -R www-data:www-data /var/www/upload/image && chmod -R 755 /var/www/upload/image
```

`RUN chown -R www-data:www～` の部分は、画像を保存する処理が可能になるように、その保存先フォルダの所有者をWebサーバーが使うユーザーに設定

`&&` の後では、保存先フォルダに対するパーミッションを設定して、所有者や、グループユーザー、その他ユーザーについて、適切な権限を設定


## php.iniの設定

`php.ini` というファイル作成

```bash
vim php.ini
```

中身の記述は下記

```bash
post_max_size = 5M
upload_max_filesize = 5M

session.save_handler = redis
session.save_path = "tcp://redis:6379"
```

`post_max_size` と `upload_max_filesize`  の部分は、アップロードされるリクエストの最大サイズを制限する設定

JavaScriptが無効化されており、ブラウザでの画像縮小などが効かない場合もあるので、念のため設定

同様の設定を `default.conf` でも行ったが、こちらのほうが第二次チェックのようなイメージ
